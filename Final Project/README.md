### 📖 รายละเอียดโครงการ (Project Overview)
**Menu Roulette** เป็นโครงงานหลัก (Final Project) สำหรับวิชา **Script Programming** พัฒนาระบบสุ่มและแนะนำเมนูอาหารอัจฉริยะ เพื่อแก้ปัญหา "วันนี้จะกินอะไรดี?" โดยมีระบบคัดกรองตามหมวดหมู่อาหาร งบประมาณ และความต้องการของผู้ใช้

### 🚀 คุณสมบัติเด่น (Features)
- 🎲 ระบบสุ่มเมนูอาหาร (Roulette Wheel Mechanism)
- 🥗 คัดกรองตามประเภทอาหาร (คาว, หวาน, เครื่องดื่ม, อาหารคลีน)
- 💰 กำหนดขอบเขตราคาและงบประมาณต่อมื้อ
- 📱 อินเทอร์เฟซใช้งานง่าย สะดวก รวดเร็ว
