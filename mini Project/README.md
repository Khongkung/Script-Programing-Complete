### 📖 รายละเอียดโครงการ (Project Overview)
**Mini Game Hub** เป็นโครงงานย่อย (Mini Project) สำหรับวิชา **Script Programming** โดยพัฒนาเกมทายคำศัพท์ภาษาอังกฤษ (Hangman) ที่ผสานตรรกะ AI ในการวิเคราะห์และสุ่มคำศัพท์ตามระดับความยาก

### 🚀 คุณสมบัติเด่น (Features)
- 🎯 ระบบเกมคำศัพท์ Hangman แบบ Interactive บนคอนโซล
- 🤖 ระบบสุ่มคำศัพท์และประเมินระดับความยาก
- 📊 บันทึกคะแนนและประวัติการเล่น
